# TV Guide Europe

A modern web application for browsing European television schedules.

## Features

- Browse TV guides across multiple European countries
- View program schedules and details
- Responsive design for desktop and mobile

## Development

### Prerequisites

- Node.js 16+
- npm or yarn

### Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment

This project is deployed on Netlify with serverless functions for backend operations.

### Environment Variables

Create a `.env.local` file in the root directory with your configuration:

```
VITE_API_URL=your_api_url
```
